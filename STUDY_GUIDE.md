# 📚 Guia de Estudos para Certificações

## 🎯 AWS Solutions Architect Professional

### Pré-requisitos
- ✅ AWS Solutions Architect Associate (obrigatório)
- ✅ 2+ anos de experiência prática com AWS
- ✅ Conhecimento profundo de múltiplos serviços AWS

### Tempo de Estudo Recomendado
- **Com experiência:** 2-3 meses (2-3h/dia)
- **Sem experiência:** 4-6 meses (3-4h/dia)

### Recursos de Estudo

#### Cursos Online
1. **A Cloud Guru / Pluralsight**
   - AWS Certified Solutions Architect - Professional
   - Hands-on Labs inclusos

2. **Udemy - Adrian Cantrill**
   - Curso mais completo e atualizado
   - Laboratórios práticos extensivos

3. **Linux Academy / A Cloud Guru**
   - Sandbox environments
   - Practice exams

#### Documentação Oficial
- [AWS Well-Architected Framework](https://aws.amazon.com/architecture/well-architected/)
- [AWS Whitepapers](https://aws.amazon.com/whitepapers/)
- [AWS Architecture Center](https://aws.amazon.com/architecture/)

#### Prática
- **AWS Free Tier** - Prática hands-on
- **AWS Workshops** - Cenários reais
- **Practice Exams** - Tutoria Dojo, Whizlabs

### Domínios do Exame

1. **Design for Organizational Complexity (26%)**
   - Cross-account strategies
   - Multi-region architectures
   - Hybrid connectivity

2. **Design for New Solutions (29%)**
   - Security requirements
   - Business continuity
   - Performance objectives

3. **Continuous Improvement (25%)**
   - Troubleshooting
   - Operations excellence
   - Cost optimization

4. **Accelerate Workload Migration (20%)**
   - Migration strategies
   - Application migration
   - Data migration

### Dicas para o Exame

✅ **Faça:**
- Leia TODAS as opções antes de responder
- Elimine respostas obviamente erradas
- Marque questões difíceis para revisar
- Gerencie bem o tempo (180 min / 75 questões)
- Foque em cenários complexos e multi-serviço

❌ **Evite:**
- Respostas que usam serviços não-AWS
- Soluções muito simples (geralmente erradas)
- Pressa - leia com atenção
- Decorar - entenda os conceitos

### Checklist de Preparação

- [ ] Completar curso online (100%)
- [ ] Ler AWS Well-Architected Framework
- [ ] Ler 10+ whitepapers relevantes
- [ ] Fazer 5+ practice exams (score > 80%)
- [ ] Hands-on com 20+ serviços AWS
- [ ] Revisar questões erradas
- [ ] Agendar exame

## 🎯 AWS Solutions Architect Associate

### Tempo de Estudo
- **Com experiência:** 1-2 meses
- **Iniciante:** 3-4 meses

### Recursos Principais
1. **Stephane Maarek - Udemy**
   - Curso mais popular
   - Atualizado constantemente

2. **AWS Skill Builder**
   - Gratuito
   - Conteúdo oficial

3. **Practice Exams**
   - Tutoria Dojo (recomendado)
   - AWS Official Practice Exam

### Serviços Essenciais
- **Compute:** EC2, Lambda, ECS, EKS
- **Storage:** S3, EBS, EFS, Storage Gateway
- **Database:** RDS, DynamoDB, Aurora, ElastiCache
- **Networking:** VPC, Route 53, CloudFront, ELB
- **Security:** IAM, KMS, Secrets Manager, WAF
- **Management:** CloudWatch, CloudTrail, Config

## 🔶 OCI Cloud Architect Associate

### Tempo de Estudo
- **Com experiência AWS:** 1-2 meses
- **Iniciante:** 2-3 meses

### Recursos
1. **Oracle University**
   - Curso oficial
   - Gratuito com Oracle Cloud Free Tier

2. **OCI Documentation**
   - Muito completa
   - Exemplos práticos

3. **Hands-on Labs**
   - OCI Free Tier
   - Oracle LiveLabs

### Diferenças AWS vs OCI
- **Networking:** Mais flexível no OCI
- **Pricing:** Geralmente mais barato
- **Compute:** Shapes flexíveis
- **Database:** Autonomous Database (diferencial)

## 💡 Dicas Gerais de Estudo

### Método de Estudo Eficaz

1. **Teoria (30%)**
   - Assistir cursos
   - Ler documentação
   - Fazer anotações

2. **Prática (50%)**
   - Hands-on labs
   - Criar projetos pessoais
   - Experimentar serviços

3. **Revisão (20%)**
   - Practice exams
   - Flashcards
   - Revisar erros

### Cronograma Sugerido

**Semana 1-4: Fundamentos**
- Assistir curso completo
- Fazer anotações
- Labs básicos

**Semana 5-8: Aprofundamento**
- Hands-on extensivo
- Projetos práticos
- Whitepapers

**Semana 9-10: Preparação Final**
- Practice exams
- Revisar pontos fracos
- Simulados

**Semana 11-12: Revisão**
- Revisar todos os tópicos
- Fazer mais simulados
- Agendar exame

### Ferramentas Úteis

- **Anki** - Flashcards
- **Notion** - Anotações organizadas
- **Draw.io** - Diagramas de arquitetura
- **AWS CLI** - Prática via linha de comando
